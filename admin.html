架构总览

后台现在只保留管理职责，支付、通知、自动发货继续由服务层独立执行。

核心层统一登录 / 导航 / 输入 / 弹窗 / 移动端
业务层模块化搜索 / 收藏 / 订单 / 固定模块
后台层控制中心只管理，不复制业务逻辑
服务层独立Supabase / 支付 / Worker / TG / 发货
前台核心层唯一登录、唯一下单/付款、唯一导航、统一输入/键盘、统一弹窗与移动端规则。
业务模块层AI搜索、四个固定模块、收藏、会员订单、站内信，以及后续新增模块，只调用核心层能力。
后台控制层会员、订单、商品/方案、答案库、固定模块、站内信、交付资料、设置、通知状态统一从这里管理。
后台服务层Supabase数据、支付核验、Worker、唯一TG机器人、自动发货保持独立，不向页面复制实现。
已移除旧后台“本机工作版 / 模拟付款 / 本地库存扣减”的架构定位。此控制中心不会通过 localStorage 伪造真实订单状态。
