全球优选 V1.0 工作版

打开方式：
1. 解压缩文件。
2. 打开 index.html：顾客下单网站。
3. 打开 admin.html：商品、订单、库存和网站设置后台。

本版已经实际完成：
- 全球优选正式名称
- 手机、平板、电脑自适应
- 商品分类、搜索、详情和购买
- 下载文件、卡密、账号密码、在线链接四种交付结构
- 有限库存与无限库存
- 邮箱必填、Telegram和备注选填
- 自动生成订单号与唯一小数金额
- USDT网络、钱包地址、复制和15分钟倒计时
- 订单查询
- 测试付款、库存扣减和自动交付
- 管理后台新增、编辑、删除、上下架商品
- 订单管理、库存管理和网站设置
- 数据保存在当前浏览器 localStorage

重要说明：
这是可以直接打开操作的完整工作版，但还不是公网正式运营版。
真实链上自动确认、真实邮件发送、多人共用云端数据库，需要部署后台服务后启用。
当前“测试付款成功”用于完整测试下单和交付流程。

后台修改钱包：
打开 admin.html → 网站设置 → 填写网络和真实钱包地址 → 保存。
